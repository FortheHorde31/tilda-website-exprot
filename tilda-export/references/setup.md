# Установка и подключение

## Первый запуск

Распакуй архив. Передай агенту путь к `tilda-export/SKILL.md` и попроси применить
его. Это работает и без автоматического обнаружения навыков. Для автоматического
выбора положи папку в каталог навыков, который поддерживает твой агент.
Не заменяй существующий одноимённый скилл без сравнения содержимого.

Тест без аккаунта Tilda, из папки скилла:

```sh
python3 scripts/check_export.py assets/example/manifest.json
python3 -m http.server 8765 --bind 127.0.0.1 --directory assets/example
```

Открой `http://127.0.0.1:8765/preview.html`. Останови сервер через Ctrl+C.
Python-библиотеки устанавливать не требуется. `checks.json` и `preview.html`
создаются рядом с манифестом; в скачанном архиве их может не быть.

## Подключение MCP

Источник: [официальная инструкция Tilda](https://help-ru.tilda.cc/mcp),
проверена 08.11.2026. По справке MCP доступен на Personal и Business.
Перед подключением проверь текущий тариф и возможности аккаунта.

1. Открой профиль Tilda → «MCP-сервер» → «Новый ключ».
2. Выбери свой проект, срок и нужные действия. Чтение, создание/правка блоков
   и публикация могут требовать разных разрешений.
3. Сохрани ключ в локальном хранилище секретов, которое поддерживает агент.
   Ключ показывается один раз. Не присылай его в чат и не вставляй в HTML.
4. В разделе подключения Tilda выбери своего агента. Используй актуальную
   инструкцию или команду Tilda. Не заменяй конфигурацию агента целиком.
5. Переподключи MCP. Попроси перечислить инструменты и прочитать доступные
   проекты. Сверь название и адрес нужного проекта перед первой записью.

Проверенный контракт: Streamable HTTP, `https://tilda.ru/api/mcp/`,
заголовок `Authorization: Bearer <ваш ключ>`. Это справочная форма,
а не готовый конфиг конкретного приложения. Секрет должен подставлять механизм
локальной конфигурации. Если Tilda выдаёт другой адрес, следуй её инструкции.
Ключ MCP и ключи старого Tilda API — разные способы доступа.

Если сервер не виден, проверь регистрацию, транспорт и переподключение.
При 401/403 проверь ключ, срок, проект и права. Не обходи ограничения.
Если агент не поддерживает это подключение, подготовь блоки локально и назови
причину. Ручная вставка T123 — отдельный способ загрузки.

## Запросы для читателя статьи

**Подготовка:**

> Используй tilda-export/SKILL.md. Перенеси landing/index.html в блоки Tilda.
> Сохрани дизайн и поведение. Подготовь манифест и превью. Аккаунт не меняй.

**Черновик:**

> Используй tilda-export. Проверь комплект и через Tilda MCP создай черновик
> в моём проекте «Демо». Адрес — spring-demo. При совпадении адреса не перезаписывай
> существующую страницу. Пришли ссылку и результат сверки.

**Публикация:**

> Опубликуй проверенный черновик с page ID из deployment.json в проекте «Демо».
> Проверь публичный адрес, адаптив и кнопки. Локальные исходники сохрани.

Комплект не содержит ключей и пользовательских проектов. Читателю нужны
собственные аккаунты, нужные права и агент с доступом к файлам и MCP.
