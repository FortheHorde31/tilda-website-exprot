# Tilda Export + MCP

Перенеси готовый HTML-сайт в Тильду с помощью ИИ-агента: подготовь блоки,
загрузи черновик через официальный MCP и опубликуй по своей команде.
При разборе HTML скилл проверяет загрузку шрифтов, изображений и других ресурсов.
Валидатор выдаёт подсказки по скорости; замеры и проверка браузером идут отдельно.
Это комплект к статье «Как опубликовать сайт не заходя в интерфейс Тильды».

**Начни с [установки и подключения](references/setup.md).** Затем передай
агенту [SKILL.md](SKILL.md) и свои исходники. В архиве есть демонстрационный экспорт
для проверки без аккаунта. Секретов, проектов и платных зависимостей автора нет.
Для MCP нужны собственные доступы Tilda; условия — в официальной справке.

Проверки разработчика: `python3 -m unittest discover -s scripts -v`.
