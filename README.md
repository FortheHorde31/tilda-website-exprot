# Tilda Website Export + MCP

Скилл для ИИ-агента: перенос готового HTML-сайта в Тильду через официальный
Tilda MCP, с проверкой блоков и загрузки ресурсов.

[Скачать скилл ZIP](https://github.com/FortheHorde31/tilda-website-exprot/raw/refs/heads/main/dist/tilda-export.zip) · [Инструкции агента](tilda-export/SKILL.md) · [Подключение MCP](tilda-export/references/setup.md)

## Быстрый старт

1. Скачайте ZIP и распакуйте папку `tilda-export`.
2. Передайте агенту файл `tilda-export/SKILL.md` и ваш HTML-проект. Для автоматического
   обнаружения поместите папку в каталог навыков, который поддерживает ваш агент.
3. Подключите собственный Tilda MCP по [официальной инструкции](https://help-ru.tilda.cc/mcp).
4. Попросите подготовить локальный экспорт, загрузить черновик или опубликовать страницу.
   Укажите нужный результат явно. Ключ храните в локальном хранилище, не в чате и не в HTML.

Пример запроса:

> Используй tilda-export/SKILL.md. Перенеси мой landing/index.html в блоки Тильды.
> Сохрани дизайн, тексты и функции. Проверь шрифты, изображения и приоритеты загрузки.
> Подготовь манифест, HEAD, превью и отчёт. В аккаунте пока ничего не меняй.

## Что делает скилл

- Подготавливает секции для T123 и содержимое нативных попапов T868.
- Сохраняет связанные 3D-сцены одним блоком.
- Проверяет HTML-пути, корневые классы, ID, якоря и ссылки попапов.
- Анализирует загрузку шрифтов, изображений, iframe и внешних ресурсов.
- Использует общий `head.html` в локальном превью и при загрузке через MCP.
- Предписывает проверять запись повторным чтением и сохранять состояние загрузки.
- Разделяет подготовку файлов, загрузку черновика и публикацию.

Подробности: [правила скорости](tilda-export/references/performance.md),
[правила блоков](tilda-export/references/blocks.md),
[процедура MCP](tilda-export/references/mcp-workflow.md).

## Пример без аккаунта

Нужен Python 3.10 или новее. Дополнительные Python-библиотеки не требуются.
Из клонированного репозитория:

```sh
python3 tilda-export/scripts/check_export.py tilda-export/assets/example/manifest.json
python3 -m http.server 8765 --bind 127.0.0.1 --directory tilda-export/assets/example
```

Откройте `http://127.0.0.1:8765/preview.html`. Для остановки сервера нажмите Ctrl+C.
Пример содержит две секции и попап. Подготовка проекта пользователя выполняется
агентом; скрипт проверки сам не разрезает произвольный HTML.

## Проверки и ограничения

```sh
python3 -m unittest discover -s tilda-export/scripts -v
```

В комплекте 15 автономных тестов. Статический аудит не измеряет PageSpeed.
Локальное превью приблизительно имитирует обёртки Tilda. Внешний вид, JavaScript,
формы и фактическую скорость проверяют отдельно в браузере. Рост балла не гарантирован.
Скилл не экспортирует сайт из Тильды на внешний хостинг и не разворачивает backend.
Для работы с аккаунтом нужны собственные доступы и агент с поддержкой Tilda MCP.
